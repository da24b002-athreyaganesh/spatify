# EDA: Spotify Tracks Dataset

Generated by `scripts/eda.py` from `data/raw/spotify_tracks.csv`. Regenerate with `dvc repro eda`.

## Overview

- 114,000 rows, 20 columns (after dropping the unnamed row index).
- 89,741 unique track IDs in 114 genres.
- Rows per genre: 1,000 to 1,000; the genre balance is artificial.

## Missing values

| column | missing |
|---|---|
| artists | 1 |
| album_name | 1 |
| track_name | 1 |

## Duplicates

- Exact duplicate rows: 450.
- Tracks listed under more than one genre: 16,299
  (up to 9 genres for one track).
- Columns whose value differs between rows of the same track: popularity (720 tracks).
  The audio features never differ, so the features stage merges these rows into one
  track and keeps the highest popularity.

  138 of them in the "sleep"
